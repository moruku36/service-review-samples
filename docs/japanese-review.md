# Japanese UI and workflow review method

Up to five web screens, one agreed workflow and 500 English source words. Supply English source strings, existing Japanese text, screenshots and test steps. Use a demo with fictional data or supplied screenshots; no real payments, account deletion or permission changes.

Check technical meaning, terminology, button/action consistency, errors, tone, truncation and the agreed Japanese input behavior. If accessible in the supplied test environment, record Unicode/full-width input, Japanese date/time presentation and layout observations. Report only what was inspected; no promise of all browsers or devices.

Deliver a correction table (screen/key, current text, suggested Japanese, reason) and reproducible UI observations with severity. This does not include implementation, full-site translation, SEO/ASO, legal/privacy-policy translation or a security audit.
