# 小さなアプリ・クラウドレビューのサンプル

Kentaro Moriが提供する限定レビューの範囲、確認手順、架空報告例を公開しています。[English](README.md)

- AI生成Webアプリ：1機能のログイン・アクセス権限を重点確認

[価格と条件](docs/services.md)、[掲載文](docs/listings.md)、[ローカル検証記録](docs/validation.md)を参照してください。

サンプルは架空データです。顧客案件の実績・本番環境の安全性・全項目の網羅を証明しません。検査スクリプトは手動で整理した設定スナップショットの3項目を見る例で、実クラウドには接続しません。実案件では資料の出所・権限・対象・限界を明記し、資料不足を安全と判定しません。
